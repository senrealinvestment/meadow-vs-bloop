# Meadow vs Bloop

K–1 reading RPG vertical slice: sound out a CVC word → Spark Strike → beat Bloop (3 hits) → open the chest.

## Play

Open the deployed Vercel URL, or open `index.html` locally.

Modes: **Parent Confirm** or **Pick the word**. Miss = same word, no shame.

## Stack

Static HTML/CSS/JS. No build step.
