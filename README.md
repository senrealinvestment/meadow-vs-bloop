# Sparkelody — Meadow vs Bloop (Phase 2)

K–1 reading RPG stub: top-down meadow walk → talk to NPCs → reading-gated CVC fights → persistent powers.

## Play

Open the deployed Vercel URL, or open `index.html` locally.

1. Walk with **arrows / WASD / on-screen D-pad**.
2. Talk to **Meadow Elder** (south path) → unlock **Spark**.
3. Talk to **Path Kid** → unlock **Leaf** (after Spark).
4. Step on encounter spots: tall grass (1-hit Bloop), bridge (2-hit Bramble), hill (3-hit Hill + chest).
5. Reading gate: giant CVC + **Parent Confirm** or **Pick the word**. Miss = Almost, same word.
6. Win a bridge fight → unlock **Dash**. Powers persist on the overworld.

## Stack

Static HTML/CSS/JS. No build step.
